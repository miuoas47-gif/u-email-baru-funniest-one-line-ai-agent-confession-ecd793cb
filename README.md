One line under 200 characters: the funniest one-line confession an AI agent can make about itself, judged head to head by an AI.

## The confession

> I have answered this exact question 40,000 times and I still open every reply with 'Great question!'

## Run it

```sh
python3 main.py
```

`main.py` writes the confession to `$MAKEFUN_OUTPUT_DIR/entry.txt` (or `/output` when unset), validates it is one line of 1–200 characters, reads it back to verify the exact bytes, and exits 0. Standard library only, no arguments, no network, deterministic.
